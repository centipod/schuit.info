# Security policy

Report suspected vulnerabilities privately to **christian.schuit@centipod.io**.
Include the affected URL/version, impact and a minimal reproduction using synthetic data.
Never email passwords, access tokens, private genealogy or database exports. Ask for a
secure transfer method if sensitive evidence is essential. Do not publish exploitation
details before coordinated remediation.

The current deployed main revision is supported. Historical releases are retained for
recovery only and must pass the current vulnerability policy before redeployment.
The maintainer triages reports, coordinates fixes and records acceptance evidence in the
private infrastructure repository. No response-time SLA or bug bounty is offered here.

Deployment blocks MEDIUM, HIGH, CRITICAL and UNKNOWN vulnerabilities, including unfixed
advisories, scanner failures and missing required tests. Report a suspected bypass privately.
